\section*{Main Tools of a Data Scientist}

\begin{itemize}
    \item \textbf{Programming and Collaboration Tools:} LaTeX/Markdown, Git/GitHub, Linux command line, SSH
    
    \item \textbf{Programming Languages for Data Collection and Statistical Modeling:} R, Julia, Python
    
    \item \textbf{Big Data Management:} SQL, RDDs (Resilient Distributed Datasets) including Spark and Hadoop
    
    \item \textbf{High-Performance Computing Resources:} SSH (Secure Shell), SFTP (Secure File Transfer Protocol), SLURM (Simple Linux Utility for Resource Management)
    
    \item \textbf{Data Collection Methods:} APIs, Web scraping
    
    \item \textbf{Data Cleaning and Visualization:} Best practices for preparing and visualizing data
    
    \item \textbf{Computational Methods:} Optimization, root finding, Monte Carlo simulations, parallel computing
    
    \item \textbf{Machine Learning:} Supervised and unsupervised learning, model training and validation
    
    \item \textbf{Economic Modeling:} Computing structural models for policy analysis
\end{itemize}
