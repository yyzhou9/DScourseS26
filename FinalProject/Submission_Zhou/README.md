## 1. Overview

This project examines whether firms with different levels of pre-mandate human capital disclosure (HCD) intensity experienced differential changes in their earnings response coefficients (ERC) following the SEC's 2020 Regulation S-K Item 101 amendment. The main empirical specification is a firm-year panel regression with the triple interaction `Post × HCD × UE`, estimated on 17,544 firm-year observations from 3,248 U.S. firms over FY2017–FY2023.

## 3. Data sources

The notebook reads from the following raw databases. **All paths are hard-coded at the top of the notebook (Section 0) and must be updated before running.**

| Source | File | Variable used |
|---|---|---|
| Compustat annual fundamentals (WRDS) | `funda.sas7bdat` | earnings, total assets, shares outstanding, fiscal year-end, SIC |
| Compustat quarterly fundamentals (WRDS) | `fundq.sas7bdat` | Q1 market value scaler |
| CRSP monthly stock file (WRDS) | `msf_v2.sas7bdat` | monthly returns |
| CRSP market index (WRDS) | `msi.sas7bdat` | value-weighted market return |
| CCM link table (WRDS) | `ccmxpf_lnkhist.sas7bdat` | gvkey ↔ permno linkage |
| IBES (WRDS) | `act_epsus.sas7bdat`, `statsum_epsus.sas7bdat`, `security.sas7bdat` | analyst-based UE (alternative measure) |
| Pre-period HCD intensity (precomputed) | `hcd_exposure.csv` | firm-level mean of Item 1 HCD intensity over FY2015–FY2019 |

`hcd_exposure.csv` is a precomputed input. Each row is a unique `gvkey` with the firm's average Item 1 HCD intensity over FY2015–FY2019, constructed by applying the Demers, Wang, and Wu (2024) HCD lexicon to 10-K Item 1 text downloaded from SEC EDGAR.

## 5. How to reproduce

### Step 1: Update file paths

Open `erc_hcd_v9.ipynb` and edit the constants in **Section 0 (Configuration)**:

- `DB` – directory containing the Compustat / CRSP SAS files
- `IBES_DB` – directory containing the IBES SAS files
- `PATH_HCD` – full path to `hcd_exposure.csv`
- `OUT_DIR` – output directory (tables and the figure will be saved here)

### Step 2: Run the notebook end-to-end

```bash
jupyter nbconvert --to notebook --execute erc_hcd_v9.ipynb --output erc_hcd_v9.executed.ipynb
```

The notebook will:
1. Load Compustat, CRSP, and IBES data; apply standard filters.
2. Merge with `hcd_exposure.csv` to obtain firm-level pre-mandate HCD intensity.
3. Construct buy-and-hold returns and four unexpected-earnings measures.
4. Build the strict regression sample (±3 fiscal years around FY2020).
5. Run the main ERC regression with the `Post × HCD × UE` interaction.
6. Run the robustness grid (FY2020 vs FY2021 cutoffs, ±3 vs ±5 windows, with and without FY2020).
7. **Generate `fig_hcd_distribution.png` (Figure 1).**
8. Print Tables 1–4 in the format used in the paper.

Total runtime is approximately 5–10 minutes depending on disk speed.

### Step 3: Compile the report

From the project directory:

```bash
pdflatex PS_Final_Zhou.tex
bibtex   PS_Final_Zhou
pdflatex PS_Final_Zhou.tex
pdflatex PS_Final_Zhou.tex
```

`fig_hcd_distribution.png` must be in the same directory as `PS_Final_Zhou.tex` before compilation. The `bibtex` step compiles the bibliography from `References_Zhou.bib`; running `pdflatex` twice afterward resolves all cross-references.

The final output is `PS_Final_Zhou.pdf`.

## 7. Notes

- All continuous regression variables are winsorized at the 1st and 99th percentiles.
- All regressions include firm and year fixed effects; standard errors are clustered by firm.
- Financial firms (SIC 6000–6999) and utilities (4900–4949) are excluded.
- The notebook is deterministic; results are reproducible bit-for-bit given the same input data.
